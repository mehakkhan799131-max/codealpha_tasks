# Quote Generator App (React JS)

## 📌 Task Description
This Quote Generator Application is developed using React JS as part of the CodeAlpha January Internship tasks.

## 🚀 Features
- Displays a random quote on page load
- "New Quote" button to generate a different quote
- Shows quote text and author clearly
- Minimal and clean UI for better user experience

## 🛠 Technologies Used
- React JS
- JavaScript (ES6)
- HTML5
- CSS3

## ▶ How to Run the Project
1. Download or clone the repository
2. Open the project folder
3. Run the following commands:

   npm install
   npm start

4. The app will run on http://localhost:3000
