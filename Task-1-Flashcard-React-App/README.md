# Flashcard App (React JS)

## 📌 Task Description
This Flashcard Application is developed using React JS as part of the CodeAlpha January Internship tasks.

## 🚀 Features
- Create and display flashcards
- Flip cards to view answers
- Clean and interactive UI
- Component-based architecture

## 🛠 Technologies Used
- React JS
- JavaScript (ES6)
- HTML5
- CSS3

## ▶ How to Run the Project
1. Download or clone the repository
2. Open the project folder
3. Run the following commands:

   npm install
   npm start

4. The app will run on http://localhost:3000

- src/
